# 字段对照表 — 电子元器件行业使用指南

> jshERP 原字段 → 深圳晶科芯/华富微业务场景映射

---

## 一、商品信息 (jsh_material)

### 基本信息

| jshERP 字段 (UI标签) | 数据库列 | 行业对应 | 说明 |
|---|---|---|---|
| **名称** ⚡ | `name` | 物料名称 | 填写完整型号名，如 `ADXL345BCCZ-RL7` |
| **型号** | `model` | **料号 / Part No.** | 行业核心字段，型号即料号 |
| **规格** | `standard` | 规格描述 | 如 0603、0805、LQFP-48、SOT-23 |
| **封装** | `color` | **封装 / Package** | 已改名(原"颜色")，如 QFN-16、SOP-8 |
| **品牌** | `brand` | 品牌 | 如 ST、TI、NXP、ADI |
| **制造商** | `mfrs` | 制造商 | 与品牌通常相同，可填全称 |
| **类别** | `categoryId` | 物料分类 | IC、电阻、电容、连接器、晶振等 |
| **单位** ⚡ | `unitId` | 计量单位 | pcs、个、卷、盘、Kpcs |

### 扩展字段 (可自定义标签)

| UI标签 (默认) | 数据库列 | 建议用途 | 自定义方法 |
|---|---|---|---|
| 扩展1 | `otherField1` | 可改为"原厂料号"、"等级"等 | 系统配置 → 商品属性 |
| 扩展2 | `otherField2` | 可改为"RoHS"、"ESD"等 | 同上 |
| 扩展3 | `otherField3` | 备用 | 同上 |

### 库存相关

| jshERP字段 | 数据库列 | 行业对应 | 说明 |
|---|---|---|---|
| **有无批号** | `enableBatchNumber` | 批次/LOT号 | 已默认开启。入库时填批次号，出库时可选择或输入 |
| 有无序列号 | `enableSerialNumber` | — | 一般不用 |
| 保质期(天) | `expiryNum` | — | 用不到（食品/药品设计） |
| 基础重量(kg) | `weight` | — | 基本不用 |
| 仓位货架 | `position` | 货架位置 | 可选，如 "A架-3层-2号" |

### 价格信息 (jsh_material_extend)

| jshERP字段 | 行业对应 | 说明 |
|---|---|---|
| 商品条码 | 内部编码/Barcode | 每物料可设条码 |
| 采购价 | 采购单价 | 入库时的成本价基准 |
| 零售价 | 建议零售价 | 参考价 |
| 销售价 | 销售单价 | 给客户的标准报价 |

## 二、供应商/客户信息

### 供应商 (jsh_supplier)

| jshERP字段 | 行业对应 |
|---|---|
| 名称 ⚡ | 供应商名称（如 华强北XX电子） |
| 联系人 | 对接人姓名 |
| 手机号码 | 手机 |
| 联系电话 | 座机 |
| 电子邮箱 | 邮箱 |
| 传真 | 传真（外贸常用） |
| 纳税人识别号 | 税号 |
| 税率(%) | 开票税率 |
| 开户行/账号 | 付款银行信息 |
| 地址 | 地址 |
| 期初应付 | 上线时未结的应付金额 |
| 期末应付 | 系统自动计算（只读） |

### 客户 (jsh_customer)

字段基本与供应商一致，差异：
- 期初**应收** → 上线时客户欠款
- 期末**应收** → 系统自动计算

## 三、采购流程

```
采购申请(可选) → 采购订单 → 采购入库 → 财务付款
                    │               │
                    └── 关联订单 ────┘
```

### 采购订单关键字段

| 字段 | 说明 |
|---|---|
| 供应商 ⚡ | 选择供应商 |
| 单据日期 | 下单日期 |
| 税率 | 默认从供应商带出 |
| 优惠率/金额 | 折扣 |
| 结算账户 | 收款账户 |
| 其它费用 | 运费等杂费 |

### 采购入库关键字段

| 字段 | 说明 |
|---|---|
| 供应商 ⚡ | 从关联订单带出 |
| 关联订单 | 可关联采购订单 |
| 仓库名称 ⚡ | 入库到哪个仓库 |
| 批号 | 输入批次号 |
| 有效期 | 不用填（食品设计） |
| 本次欠款 | 未付金额 |
| 其它费用 | 额外费用 |

### 明细行字段

条码 → 名称 → 规格 → 型号 → 封装 → 品牌 → 制造商 → 扩展1/2/3 → 库存 → 单位 → 数量 → 单价 → 金额 → 税率 → 税额 → 价税合计 → 备注

---

## 四、销售流程

```
销售订单 → 销售出库 → 财务收款
   │           │
   └── 关联 ──┘
```

与采购对称，主体换为客户。多出 `销售人员` 字段。

## 五、报表对应行业理解

| 报表名称 | 行业用途 |
|---|---|
| **商品库存** | 查看当前各物料库存总量 + 批次明细 |
| 入库明细 | 按时间段查所有入库记录 |
| 出库明细 | 按时间段查所有出库记录 |
| 入库统计 | 按物料汇总入库数量/金额 |
| 出库统计 | 按物料汇总出库数量/金额 |
| 采购入库报表 | 按物料汇总采购/退货/净采购 |
| 销售出库报表 | 按物料汇总销售/退货/净销售 |
| 库存预警 | 设置安全库存，低于阈值提醒补货 |
| 进销存报表 | 月度/季度进销存汇总 |
| 调拨明细 | 仓库间调拨记录 |

## 六、行业特有需求 vs 系统能力

| 需求 | 系统能力 | 状态 |
|---|---|---|
| 料号管理 | 型号字段复用 | ✅ 可用 |
| 封装管理 | 颜色字段已改名 | ✅ 已完成 |
| 批次追踪 | 批号功能已默认开启 | ✅ 已完成 |
| 批次库存查看 | 库存详情已支持展开批次 | ✅ 已完成 |
| 供应商价格管理 | 多单位多价格 | ✅ 可用 |
| 采购入库流程 | 采购订单→入库 | ✅ 可用 |
| 销售出库流程 | 销售订单→出库 | ✅ 可用 |
| 品牌筛选 | 品牌字段 | ✅ 可用 |
| 最小包装量 | 需用多单位功能 | ⚠️ 需配置 |
| 批号独立使用(不要有效期) | 当前强绑定 | ⏳ 待解耦 |
| RoHS/环保标识 | 需用扩展字段 | ⚠️ 需配置 |
